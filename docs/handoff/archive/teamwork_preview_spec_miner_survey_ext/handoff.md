## 2. Logic Chain
1. From Observation 1 and Observation 2, `apps/browser-extension/` is already structured with Manifest V3 and background service worker module routing. Adding YouTube Clip Mode requires expanding `manifest.json` (`"sidePanel"` permission, `"*://*.youtube.com/*"` host permissions, `"side_panel"` declaration, and `content/youtubeAdapter.js` content script).
2. From Observation 2 and Observation 3, the deterministic RSA public key in `manifest.json` produces the fixed extension ID `bnpmffibedppchkljkcaidgijekgfmgl`. This ID strictly matches `allowed_origins` in both `tools/native_host/com.vkdub.bridge.json` and the dynamic `%LOCALAPPDATA%` manifest generated by `src/vkdub/bridge/registry.py`. Therefore, native messaging authorization is already aligned across Chrome and Edge.
3. In YouTube's DOM, mounting the toolbar requires Shadow DOM encapsulation within `#movie_player`. Without Shadow DOM and `stopPropagation()` on click events, clicks on toolbar buttons would toggle YouTube playback or trigger native YouTube events.
4. YouTube natively binds hotkey `i` to toggle the Miniplayer. If `youtubeAdapter.js` does not intercept `i` in the capturing phase (`useCapture: true`) with `e.preventDefault()` and `e.stopImmediatePropagation()`, pressing `i` to set an in-point would collapse the player into a miniplayer.
5. YouTube SPA navigation (`yt-navigate-finish`, `yt-page-data-updated`) re-uses `#movie_player` and swaps `<video>` media streams. If the adapter indiscriminately mounts a new toolbar element on every event, stacked duplicate overlays will degrade the interface. A singleton controller (`window.__vkdubYoutubeAdapter`) that checks `currentVideoId`, updates metadata, rebinds video listeners, and resets marker state in-place completely prevents duplicate nodes.
6. In `apps/browser-extension/sidepanel/`, creating `index.html`, `sidepanel.css`, and `sidepanel.js` provides the full client-side clip management workflow: video info card, draggable list with HTML5 DnD, inline timecode parsing (`HH:MM:SS.mmm`, `MM:SS`, seconds), client-side bounds validation (`start < end <= duration`, `end - start >= 0.5s`), duplicate segment prevention, and realtime export progress telemetry via `CLIP_EXPORT_PROGRESS`.
7. Because all YouTube and Clip Export message actions (`YOUTUBE_*`, `CLIP_EXPORT_*`) reside in distinct action namespaces, existing ChatGPT and Vbee automation routes remain 100% untouched and regression-free.
